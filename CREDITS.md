# Credits

The project owner supplied the User Machine library, grouped by author:

| Author | Machines |
| --- | ---: |
| dbx | 2 |
| jmamma | 55 |
| minimal | 4 |
| murdenihcam | 13 |
| waftlord | 56 |

SysEx files are unchanged. PNG files from dbx, murdenihcam, and waftlord are
also unchanged originals. The jmamma images were generated from the supplied
`USR-Machines/README.txt` and package metadata in the local X.20-C collection.
See [sources and generation](machines/jmamma/README.md).

**minimal** contributes the experimental **CROSSFIELD RVB-XA + RVB-XB** pair,
revision r0001. Its English cards were generated from the original package
metadata and project documentation, with the owner's DSP-load and external-input
usage notes. See [CROSSFIELD sources and status](machines/minimal/README.md).
The **NFX-OT r0003** mono compressor and its English card also come from
minimal's project sources; see [NFX-OT sources and status](machines/minimal/NFX-OT.md).
The **NFX-DC r0001** decorrelator and its English card follow the same process;
see [NFX-DC sources and status](machines/minimal/NFX-DC.md).

Author credits and descriptions correspond to the original files. This
repository does not grant a blanket license for these third-party materials.

The implementation follows the MDS/MDX sources pinned in `toolchain.lock.json`.
No Machinedrum firmware or ROM files are provided. WebLoader is an independent
project.
